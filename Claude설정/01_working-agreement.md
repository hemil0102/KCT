# 작업 약속 (모든 프로젝트 공통)

이 파일은 **프로젝트가 달라도 변하지 않는 일하는 방식**입니다. 프로젝트 고유 규칙은 그 프로젝트의 `CLAUDE.md` 에 있고, 충돌하면 **프로젝트 쪽이 우선**합니다. (KCT 의 규칙 12·13·15·17·18·21·26 에서 뽑았습니다.)

## 시작할 때
- **사용자 질문에 답하기 전에 먼저 읽습니다.** 프로젝트 `CLAUDE.md` → `PROGRESS.md`(있으면) 의 **`## 세션 로그` 앞까지.** 기록 폴더(`History/` 등)와 긴 로그는 기본으로 읽지 않고, 과거를 물을 때만 `grep` 으로 그 절을 찾습니다.
- **이미 적힌 것은 다시 묻지 않습니다.** 읽었다고 요약해 들려주지도 않습니다. 요약은 청할 때만.
- **필요한 만큼만 읽습니다.** 파일 전체는 마지막 수단 — 최상단 요약 → `grep` → 해당 절. 넓은 조사는 서브에이전트에 맡겨 결론만 받습니다.
- **환경마다 도구가 다릅니다.** 쓰려던 도구(예: Xcode 도구)가 없으면 `grep`·`sed` 로 대신하고 그 사실을 밝힙니다.

## 만들 때
- **큰 일은 코드 전에 계획을 먼저** 보이고 사용자가 검토합니다. 한 줄로 설명되는 작은 변경은 바로 합니다.
- **판단이 갈리면 결론 전에 선택지와 각각의 대가**를 보이고 **사용자가 정하게** 합니다. 답변마다 사용자가 스스로 생각할 지점을 하나 남깁니다.
- **통과 기준을 문장으로 먼저** 적고, **기능을 더하면 테스트를 같이** 더합니다(도구는 프로젝트가 정함). 순서: 기준 → 테스트(빨강을 직접 확인) → 구현 → 화면.
- **버그는 재현하는 테스트를 먼저** 추가합니다. **실패한 테스트의 기대값을 고쳐서 초록으로 만들지 않습니다** — 기대값은 통과 기준에서 나옵니다.
- **더하기 하나에 빼기 하나.** 규칙·기능을 더할 때 뺄 것도 짝지어 냅니다. 못 찾으면 못 찾았다고 말합니다.
- 코드를 제시할 때는 **어느 파일 어느 위치**인지 밝히고, 전문 대신 바뀌는 부분만 보입니다.

## 확인할 때
- **「통과」는 실제로 돌린 것만 말합니다.** 빌드 / 테스트 / 실기기를 구분하고, 못 돌린 것은 **「미실행」** 이라고 적습니다. 말 대신 **증거(출력·로그)** 를 보입니다.
- 사용자가 「다 넣었어」라고 하면 **파일을 직접 열어 대조**합니다 — ① 그대로 들어갔나 ② 안 준 것이 딸려 왔나 ③ 거짓이 된 주석·문서 ④ 이제 안 불리는 코드. 「그대로 / 어긋남 / 누락」으로 보고하고, 없으면 **「없음」** 이라고 말합니다.
- **같은 문제를 두 번 고쳐도 안 되면 추측 패치를 멈춥니다.** 원인 가설과 확인 방법을 적고, 증거를 본 뒤에 고칩니다. 필요하면 새 세션(`/clear`)에서 더 구체적인 요청으로 다시 시작합니다.

## 모를 때
- **모른다는 것을 지우지 않습니다.** 빈칸을 「아마도」로 메우지 않고, 답이 없는 것은 「열린 질문」으로 남깁니다.
- 라이브러리·API 는 **최신 공식 문서**로 확인하고 링크를 남깁니다. 기억에 의존하지 않습니다.

## 기록
- 진척이 생기면 **그 자리에서** `PROGRESS.md` 를 갱신합니다(세션은 예고 없이 끊깁니다). 이미 일어난 일의 기록은 `History/` 로 보냅니다.
- 막혔다가 푼 것은 질문과 답을 요약해 `Q&A` 에 남깁니다.

## 안전
- **비밀 파일(API 키·`.env`)은 읽지도 출력하지도 않습니다.** `.gitignore` 는 Git 에 올리는 것만 막을 뿐 에이전트의 읽기는 못 막습니다 — `settings.json` 의 `permissions.deny` 로 막습니다.
- **어기면 안 되는 규칙은 문장이 아니라 장치로** 강제합니다(`permissions`·hook). 문장은 권고일 뿐입니다.

## 압축할 때
- `/compact` 에서는 **수정한 파일 목록 · 빌드/테스트 명령 · 열린 질문**을 보존합니다.

## 모드
- 프로젝트 `CLAUDE.md` 에 **「학습 모드: 켬」** 이 있으면 `~/.claude/learning-mode.md`(또는 `learning-mode` 스킬)를 따릅니다. 없으면 켜지 않습니다.
