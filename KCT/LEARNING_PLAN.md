# KCT 학습 앱 — 설계 및 진행 계획

_살아있는 문서. 단계가 끝날 때마다 갱신한다._
_최종 갱신: 2026-08-15_

## Context (배경)

귀화 시험 준비 앱. 사용자(어머니, 70대)가 **선택을 거의 하지 않아도**, 약 1000개의
문제를 쉬운 것 → 어려운 것으로 자연스럽게 반복 학습하도록 만드는 것이 목표다.

---

## 핵심 설계 원칙

### 두 개의 축 (반드시 분리)

| 축 | 의미 | 저장 위치 | 성격 |
|----|------|-----------|------|
| **A. 문제 고유 난이도** | 문항 자체가 얼마나 어려운가 | `Question.difficulty` | **고정** |
| **B. 어머니 학습 레벨** | 얼마나 마스터했나 | `QuestionProgress.mode` | **동적** |

- 축 A = **신규 문제 도입 순서**만 결정 (쉬운 것 먼저 등장)
- 축 B = **출제 모드**(사다리). 모든 문제가 같은 사다리를 탄다

### 난이도 사다리 (축 B)

```
2지선다(0) → O/X(1) → 4지선다(2) → 직접입력(3) → 마스터
```
- 맞히면 한 단계 ↑, 틀리면 한 단계 ↓ — **세션(날짜)을 넘어 유지**
- 직접입력까지 맞히면 마스터. 단 **마스터 후에도 랜덤으로 계속 복습 출제**
- 라운드 **첫·마지막 문제는 항상 2지선다** (격려용, 진척에 반영 안 함)

### 콘텐츠와 진척의 분리

`Question`(콘텐츠)은 교체 가능, `QuestionProgress`(진척)는 `questionID`로 연결.
⚠️ **문제 id는 영구 고정** — 재사용하면 기록이 엉뚱한 문제에 붙는다.

## 진행 현황

### ✅ 1단계 — 모드 렌더링 & 채점 (완료)

- `DifficultyMode` 4단계 사다리
- `PracticeItem` + `ModePayload` — 모드별 데이터를 문제집에서 **자동 파생**
  (선다 오답은 다른 문제 정답에서 추출, O/X는 진술문 + 랜덤 후보)
- `PracticeGrader` — 선다·O/X는 **모델 없이 즉시 비교**, 직접입력만 `AnswerGrader`(FoundationModels)
- `Question`에 `unit`(단원), `difficulty`(구 `level`), `statementFormat`(O/X 진술문) 추가

### ✅ 2단계 — 영구 진척 & 승급/강등 (완료)

- `QuestionProgress` (SwiftData `@Model`) — 모드·마스터·시도/정답 수·`nextDueAt`
- 앱을 껐다 켜도 유지. 결과 화면에 **학습 기록 초기화** 버튼(확인창 포함)

### ✅ 3단계 — 자동 스케줄러 (완료)

`SessionBuilder`가 담당:
- **복습 우선** — 미마스터 문제를 `nextDueAt` 이른 순 → 쉬운 순
- **신규 점진 도입** — `difficulty` 오름차순 + **단원 라운드로빈**
- **마스터 복습** — 세션당 1칸 확보, 랜덤 등장
- **라운드 셰이핑** — 첫·마지막 격려용 2지선다
- **스토리 게이트 seam** — `isUnlocked(question)`, 지금은 항상 true

### ✅ 묻는 대상 하이라이트 (완료) — 3층 구조

읽는 순서: **서버값 → 캐시 → 규칙 기반(즉시)**, 부족분은 백그라운드 분석.

| 층 | 파일 | 지연 |
|---|---|---|
| 규칙 기반 (의문사 닫힌 집합) | `QuestionFocus.swift` | 0 |
| 모델 분석 캐시 | `QuestionFocusRecord.swift` (@Model) | 0 |
| 백그라운드 분석 + 워밍 | `FocusAnalyzer.swift`, `FocusStore.swift` | 0 (안 기다림) |

- 캐시 키 = `문제 id + 질문 텍스트 SHA256` → **문구 수정 시 자동 재분석**
- 모델 실패·미지원 기기·환각(지문에 없는 표현) → **조용히 규칙 기반으로 폴백**
- 형광펜(연노랑)은 **연습 모드에서만** (`SessionMode.showsFocusHighlight`)

### ✅ UX / 디자인 (완료) — 유저 리서치 3차 반영

**어르신 접근성**
- 큰 글씨·고대비, 지문 30pt Bold, 터치 타깃 56pt↑
- **왼쪽 정렬 + 한글 단어 단위 줄바꿈**(`hangulWordPriority`) + **숫자·단위 묶기**(WORD JOINER)
  → `KoreanText.swift` (SwiftUI Text가 지원하지 않아 UILabel 래핑)
- **자동 낭독** — 문제 진입 시 지문 재생, "다시 읽기" 버튼 (`SpeechReader`, 남성 음성 우선)

**정보 간소화**
- 문제 유형 배지 제거 → **행동 안내 한 줄**("답을 골라보세요")로 대체
- 진행률: 텍스트 없이 **문제 수만큼 나눈 세그먼트 바**
- 안내 문구는 보기 바로 위 캡션 위치 (질문이 화면의 유일한 주인공)

**디자인 시스템** (`AppColor.swift`) — 시그니처 `#745CF4`
| 위계 | 스타일 | 쓰임 |
|---|---|---|
| Primary | 시그니처 채움 + 흰 글씨 | 다음/제출, 다시 풀기 |
| Secondary | 연보라 + 보라 글씨 | 다시 읽기 |
| Disabled | 회색 + 진회색 글씨 | 답 고르기 전 |
- 모양은 **전부 알약**. 보기 선택은 사각형 + 체크(상태 ≠ 행동)

**채점 화면** — "틀렸다" 표현 배제
- "잘하셨어요!" + **누적 맞힌 문제 수** 강조, 오답은 "다시 볼 문제 / 곧 다시 만나요"

**O/X 개선**
- 의문문 대신 **진술문** 제시(`statementFormat`), 판단 대상 답을 **보라+굵은 밑줄**
- 버튼은 "맞아요 / 아니에요"

## ⬜ 남은 작업

### 4단계 — 연습 모드 즉시 채점 (다음 후보 ★)

유저 리서치: _"연습 모드에서는 바로바로 채점, 정답이면 자신감, 오답이면 힌트로 재시도.
최종 실패면 이해 못 한 지점을 가이드."_

- 문제를 고르는 즉시 정오답 표시 (지금은 5문제 후 일괄 채점)
- 오답 시 **힌트 제공 후 재시도** 기회
- 실전 모드(`SessionMode.exam`)는 지금처럼 일괄 채점
- (리서치 과제) 이해 못 한 지점을 어떻게 파악하고 가이드할지

### 5단계 — 1000문제 데이터 & 단원 풀

- 단원별 문제 적재 (정치1·정치2·사회1·사회2 …), 균등 출제 튜닝
- `statementFormat`(O/X용)을 문제마다 작성해야 하는 부담 → 일부만 O/X 지원할지 검토

### 6단계 — 음성 입력

- `Speech` 프레임워크로 직접입력 단계의 **대체 입력수단**
- Info.plist 권한 2종 필요
- 이후 **키워드 조합** 모드는 마스터 이후 보너스로 검토

### 남은 UX 항목

- 낭독 **속도 조절** 버튼
- 다음 버튼 활성화 시 **화살표 애니메이션**

### 향후 구조 작업

- **스토리 모드** — 읽은 콘텐츠의 문제만 개방. `isUnlocked` 게이트 교체만 하면 됨
- **서버 연동** — 버전 붙은 JSON 통째 교체 + 번들 시드 + **안전한 시점에만 적용**
  (세션 도중 교체 금지). `Question.all` → 카탈로그 로더 전환 (참조 3곳뿐)
  서버가 `focusPhrase`를 함께 내려주면 하이라이트 1층이 자동으로 활성

## 파일 구성

**콘텐츠·모델**
- `Question.swift` — 문제집 + 모드별 파생(선다 보기, O/X 진술문)
- `DifficultyMode.swift` — 4단계 사다리 [축 B]
- `PracticeItem.swift` — 출제 항목 + `ModePayload` + 안내 문구
- `SessionMode.swift` — 연습/실전

**진척·출제**
- `QuestionProgress.swift` — 진척 (@Model)
- `SessionBuilder.swift` — 자동 스케줄러

**채점**
- `PracticeGrader.swift` — 결정적 채점
- `AnswerGrader.swift` — 직접입력 의미 채점 (FoundationModels)

**하이라이트**
- `QuestionFocus.swift` — 규칙 기반 추출
- `QuestionFocusRecord.swift` — 분석 캐시 (@Model)
- `FocusAnalyzer.swift` — 모델 분석
- `FocusStore.swift` — 우선순위 결정 + 백그라운드 워밍

**화면·표현**
- `QuizView.swift` — 퀴즈 화면
- `KoreanText.swift` — 한국어 조판(줄바꿈·강조·형광펜)
- `AppColor.swift` — 색 팔레트·버튼 위계
- `SpeechReader.swift` — 낭독
