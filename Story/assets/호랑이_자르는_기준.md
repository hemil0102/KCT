# 호랑이 분리 기준 (아이패드 Procreate → 웹 애니메이션)

> 근거가 공식 문서인 항목에는 (출처), 제 판단인 항목에는 (제안)이라고 적었다.

## 1. 원리 — 왜 자르는가
웹 캐릭터는 두 가지 방식으로 움직인다.
- **통째로 움직임(강체)**: 한 조각을 회전·이동·크기 조절. 조각이 따로 있어야 하고, 조각이 떨어져도 틈이 안 보이도록 **겹치는 여분**이 필요하다.
- **휘어짐(메시)**: 한 조각 위에 그물을 얹고 뼈대 영향도(가중치)로 휜다. 꼬리·털·귀처럼 구부러지는 부분에 맞다. (Rive 문서: 이미지에 메시를 붙이고 꼭짓점을 뼈대에 묶는다)

그래서 기준은 하나다. **"따로 움직이는가? 관절이 어디인가?"**
- 따로 움직이면 → 레이어를 나눈다.
- 구부러지기만 하면 → 한 레이어로 둔다(메시가 해결).
- 나눈 두 조각이 만나는 곳 → 아래 조각을 **위 조각 속으로 깊이** 그려 넣는다.

## 3. 자를 때 기준
1. **숨은 부분을 그린다** — 머리카락을 떼면 그 밑 피부까지, 팔을 떼면 어깨 안쪽까지. 넉넉하게 그릴수록 움직일 때 안 끊긴다 (Live2D 공식 튜토리얼, Clip Studio 팁).
2. **관절 끝은 둥글게** — 위팔 끝·아래팔 끝을 원 모양으로 완성해 둔다. 돌려도 모서리가 안 튀어나온다 (제안).
3. **선과 색은 한 레이어에 합친다** — 조각마다 선+채색+효과를 하나로 (Live2D PSD 주의사항).
4. **레이어 마스크·클리핑·곱하기(Multiply)는 쓰지 않는다** — 쓰면 합쳐서 내보낸다. 곱하기는 겹친 곳이 어두워진다 (Live2D, Clip Studio).
5. **이름은 겹치지 않게**, 영어/숫자, 좌우는 `_L` `_R` (Live2D PSD 주의사항 + 제안).
6. **눈·입은 덧그리지 말고 완성본으로** — 입이 겹쳐 보이던 문제는 덧그림이 원인이었다. 닫힌 입/열린 입을 각각 끝까지 그려 두면 바꿔 끼우기만 하면 된다 (제안).
7. **해상도** — 화면에 보이는 크기의 2배 이상으로 (예: 캔버스 가로 2000px 이상). 작게 그린 그림을 키우면 번진다 (제안).
8. **배경은 투명**. 참고용 원본 그림은 숨긴 레이어로 맨 아래에 (제안).

## 4. Procreate 작업 순서 (제안 — UI 동작은 버전에 따라 다를 수 있음)
1. 원본 레이어를 **복제**하고 원본은 숨겨 둔다.
2. 복제본에서 선택(올가미) → 잘라내기/붙여넣기로 조각을 새 레이어로 옮긴다.
3. 조각 레이어 **아래쪽으로** 숨은 부분을 덧그린다 (알파 잠금으로 색만 채울 수 있다).
4. 조각마다 이름을 붙이고, 머리/팔/몸 그룹 폴더로 묶는다. 그룹은 나중에 합치지 말고 폴더 그대로 둔다.
5. 합치기 전에 마스크·클리핑·블렌드 모드가 남았는지 확인한다.

## 5. 저장 (Procreate 핸드북 기준)
| 형식 | 레이어 | 쓸까 |
|---|---|---|
| **PSD** | 유지 (이름·투명도·보이기·블렌드 모드) | **이걸 주세요** |
| 레이어를 PNG 폴더로 공유 | 레이어마다 PNG 한 장 | 백업 (캔버스 크기 그대로 나오는지는 확인 필요) |
| PNG / JPEG / TIFF / PDF(이미지) | 한 장으로 합쳐짐 | 미리보기용으로 한 장만 |
| .procreate | 전부 유지 | 원본 보관용. 함께 주셔도 좋다 |

주의: **보이는 레이어만** 내보내진다. 참고용 원본은 숨긴 채로 두고, 나눈 조각은 모두 보이게 켜 둘 것.

**보내 주실 것**: ① PSD ② 합친 미리보기 PNG 한 장 ③ (선택) "이 조각은 여기를 축으로 돈다" 표시한 그림 — 없어도 제가 관절 위치는 잡는다.
