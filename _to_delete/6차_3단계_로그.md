# 6차 3단계 — 남은 것: 판정 근거를 로그에 남기기

> 코드는 다 들어갔습니다. **`basis` 를 계산은 하는데 아무도 받아 가지 않아** 서버에 빈 칸으로 남습니다.
> 고칠 곳은 **네 군데**입니다.

```
QuizSession   basis 를 만든다          ✅ 되어 있음
ObsRecord     그것을 담아 둔다          ⬜ 여기부터
ObsUploader   서버로 보낸다             ⬜
Supabase      받아서 저장한다           ⬜ 컬럼은 만들었고 정책만 남음
```

`explanation_source` 도 같은 자리라 **같이 넣습니다.** 두 번 고칠 일을 한 번으로 줄입니다.

- `basis` — 무엇을 근거로 정답/오답을 정했나 (`exactMatch` · `differentLetters` …)
- `explanationSource` — 해설을 누가 만들었나. 지금은 늘 `"device"`(온디바이스 모델)

---

## 1. Supabase — 정책에 두 줄 더하기

**`with check`** 는 INSERT 로 들어오는 새 행을 검사하는 조건입니다. 거짓이면 그 행이 거부됩니다. 길이를 재는 이유는 키를 주운 누군가가 큰 문자열을 밀어 넣는 것을 막기 위해서입니다.

정책은 줄을 덧붙일 수 없어 **조건 전체를 다시 씁니다.** SQL Editor 에 그대로 붙여 넣습니다.

```sql
alter policy "app can insert only" on public.obs_record
with check (
    question_id >= 1 and question_id <= 100000
    and mode_raw >= 0 and mode_raw <= 3
    and sec_to_submit >= 0 and sec_to_submit < 3600
    and (sec_to_first_touch is null
         or (sec_to_first_touch >= 0 and sec_to_first_touch <= sec_to_submit))
    and asked_at > (now() - interval '30 days')
    and asked_at < (now() + interval '1 day')
    and length(device_id) >= 8 and length(device_id) <= 64
    and (chosen is null or length(chosen) <= 100)
    and (reason is null or length(reason) <= 300)
    and (explanation is null or length(explanation) <= 500)
    and (explanation_source is null or explanation_source in ('cloud', 'device'))
    and (basis is null or length(basis) <= 30)
);
```

첫 줄의 따옴표 안은 **정책 이름**입니다. 다르면 바꿔 주세요.

## 2. `KCT/Observation/ObsRecord.swift`

### 2-1. 머리말 구성 목록

`├─ explanation` 줄 아래에 두 줄.

```swift
//  ├─ basis                    무엇을 근거로 판정했나
//  ├─ explanationSource        해설을 누가 만들었나 (device · cloud)
```

### 2-2. 프로퍼티

`var explanation: String?` **바로 아래.**

```swift
    /// 무엇을 근거로 판정했나. 선다·O/X 는 `nil` 입니다.
    ///
    /// 코드가 정한 것(`exactMatch`)과 모델이 고른 것(`differentLetters`)이 함께 들어오므로
    /// 열거형이 아니라 글자입니다.
    var basis: String?

    /// 해설을 누가 만들었나. `"device"` 는 기기 안의 모델입니다.
    var explanationSource: String?
```

### 2-3. `init` 인자

`explanation: String?` 아래에 두 줄. **쉼표를 잊지 마세요.**

```swift
        explanation: String?,
        basis: String?,
        explanationSource: String?
```

### 2-4. `init` 안쪽

`self.explanation = explanation` 아래에 두 줄.

```swift
        self.basis = basis
        self.explanationSource = explanationSource
```

## 3. `KCT/Observation/ObsUploader.swift`

`Payload` 는 **서버로 보낼 한 줄의 모양**입니다. 네 군데에 같은 이름을 더합니다.

### 3-1. 필드

`let explanation: String?` 아래.

```swift
        let basis: String?
        let explanationSource: String?
```

### 3-2. `CodingKeys`

`explanation` 뒤에 이어 씁니다.

```swift
            case wasFirstEver, affectsProgress, chosen, reason, explanation
            case basis, explanationSource
```

### 3-3. `encode(to:)`

`try container.encode(explanation, ...)` 아래.

```swift
            try container.encode(basis, forKey: .basis)
            try container.encode(explanationSource, forKey: .explanationSource)
```

> ⚠️ **`encodeIfPresent` 가 아니라 `encode` 입니다.** `encodeIfPresent` 는 값이 `nil` 이면 그 키를 아예 안 씁니다. 그러면 한 회차 안에서 줄마다 키 개수가 달라지고, 서버가 **회차 전체를 400 으로 거부**합니다. 예전에 겪었습니다([Q&A.md](Q&A.md)).

### 3-4. `Payload(...)` 만드는 곳

`explanation: record.explanation` 아래. **위 줄 끝에 쉼표를 더해야 합니다.**

```swift
                explanation: record.explanation,
                basis: record.basis,
                explanationSource: record.explanationSource
```

## 4. `KCT/Screens/QuizSession.swift`

`saveObsRecord(for:isCorrect:explanation:)` 안의 `ObsRecord(...)` 입니다.
`explanation: explanation` 아래에 두 줄. **위 줄 끝에 쉼표를 더합니다.**

```swift
                explanation: explanation,
                basis: results[item.id]?.basis,
                explanationSource: explanation == nil ? nil : "device"
```

해설이 없으면 만든 이도 없으므로 `nil` 입니다.

## 5. 확인

앱을 켜서 **직접입력을 한 문항 이상 풀고** 회차를 끝냅니다. 그다음 SQL Editor 에서:

```sql
select question_id, chosen, is_correct, basis, explanation_source
from obs_record
order by asked_at desc
limit 20;
```

이렇게 보이면 된 것입니다.

| 무엇 | 보여야 하는 것 |
|---|---|
| 선다·O/X | `basis` 가 비어 있음 |
| 직접입력인데 바로 맞음 | `basis` 가 `exactMatch` |
| 직접입력인데 모델이 봄 | `basis` 가 `differentLetters` · `listMatch` 등 |
| 오답 | `explanation_source` 가 `device` |

**`basis` 가 전부 비어 있으면** 3번(`ObsUploader`)에서 한 군데를 빠뜨린 것입니다.
**아무것도 안 올라오면** Xcode 콘솔에 `📤` 로 시작하는 줄과 함께 오류가 찍힙니다.
