## ① 「A와 B는 늘 짝으로 나옵니다」

### 무엇이 일어났나

```
q6 단군왕검 → "단군왕검은 늘 함께 나오는 이름입니다."     ← 뜻이 없는 말
q4 단군왕검 → "단군왕검과 고조선은 늘 같이 나옵니다."
q10 주몽    → "주몽과 애국가는 늘 같이 나옵니다."          ← 거짓
```

### 왜

`.person` 예시의 **마지막 문장** 하나가 원인이다.

```
"애국가와 안익태는 늘 짝으로 나옵니다."
```

모델이 이 문장을 **꼬리표처럼 떼어다 붙이고**, 빈칸에 아무 낱말이나 넣는다. 안익태 예시가 하나뿐이라 「애국가」까지 딸려 온다.

**오늘까지 같은 실수 세 번째다.** 고조선 예시 하나 → 모든 답에 글자 풀이. 금지 문구를 인용 → 그 문구를 따라 씀. 그리고 이번.

### 고치는 법 — 꼬리 문장을 없애고, 예시를 둘로

`.person` 의 문자열을 통째로 교체.

```swift
        case .person:
            """
            정답이 사람 이름입니다. 이름의 글자를 풀지 마세요.
            사람 이름의 글자에는 뜻이 없습니다.
            그 사람이 한 일을 하나만 말하세요.
            예) 정답 "이순신"
            "임진왜란 때 바다에서 왜적을 물리친 장군이 이순신입니다.
             거북선을 만들어 싸웠습니다."
            예) 정답 "세종대왕"
            "백성이 쉽게 읽고 쓰도록 한글을 만든 임금이 세종대왕입니다.
             조선의 네 번째 임금입니다."
            """
```

바뀐 점 셋.

- **「늘 같이 나옵니다」를 없앴다.** 베낄 꼬리표가 없어진다
- **예시를 둘로 늘렸다.** 하나면 그걸 베끼고, 둘이면 **공통점(틀)** 을 뽑는다
- **지금 20문항에 없는 사람**(이순신·세종대왕)을 골랐다. 예시의 낱말이 답으로 새어 나오지 않는다

## ② 「정답은 …입니다」로 시작

### 무엇이 일어났나

**22줄 중 16줄.** 첫 문장이 채점 결과를 읊는 말이라 버려지고, 세 문장짜리 창이 실질 두 문장이 된다.

```
정답은 고조선입니다. '고'는 옛날이라는 뜻입니다. 가장 오래된 나라입니다.
```

### 왜

규칙 5(「첫 문장은 정답이 무엇인지로 시작한다」)는 이미 지웠는데도 남았다. 원인은 **프롬프트**다 — 「정답」이라는 낱말을 두 번 보여주고 있다.

```swift
            정답: \(item.question.answer)        ← 한 번
            정답이 무엇인지 알려주는 세 문장…     ← 두 번
```

### 고치는 법

`prompt` 를 교체.

```swift
        let prompt = """
            문제: \(item.question.question)
            답: \(item.question.answer)

            이 답을 기억에 남게 알려주는 세 문장 이내의 글을 쓰세요.
            """
```

「정답」을 빼면 첫 문장이 `guide(for:)` 의 예시 모양을 따라간다 — 「우리나라의 첫 나라는 고조선입니다」.

## ③ 뜻을 모르는데 지어낸다

### 무엇이 일어났나

```
q15 한글날 → "한글은 하늘에서 내려온 글이라는 뜻입니다."     ← 거짓
```

훈민정음은 「백성을 가르치는 바른 소리」다.

### 왜

`.day` 지침이 **「날짜를 먼저 말하고 이름의 뜻을 이으세요」**라고 시킨다. 뜻을 모를 때 「모르니 넘어간다」는 길이 없어서 지어낸다. 공통 규칙 6(「확실하지 않으면 넣지 않는다」)이 있지만, **작은 모델은 자기가 확실한지 모른다.**

### 고치는 법 — 뜻을 「해도 되는 것」으로 낮춘다

```swift
        case .day:
            """
            정답이 기념일이나 명절입니다. 날짜를 먼저 말하세요.
            그다음 그날 무슨 일이 있었는지를 말하세요.
            이름의 뜻은 확실할 때만 덧붙이고, 아니면 넣지 마세요.
            예) 정답 "개천절"
            "10월 3일은 개천절입니다. 단군왕검이 고조선을 세운 것을
             기리는 날입니다."
            """
```

- **「무슨 일이 있었는지」를 주 재료로** 올렸다. 이건 문제 지문에 이미 있어서 지어낼 필요가 없다
- **이름의 뜻은 곁가지**로 내렸다
- 예시에서도 뜻풀이(「하늘이 열린 날」)를 뺐다. **예시에 있으면 따라 한다**

## 다 넣고 확인할 것

1. **q10(주몽)·q20(안익태)을 틀린다** → 「늘 같이 나옵니다」가 사라졌는가. **이번 보완의 성적표다**
2. **아무거나 틀린다** → 「정답은」으로 시작하는 줄이 몇 줄인가. 16/22 였다
3. **q15(한글날)을 틀린다** → 한글의 뜻을 지어내지 않는가
4. **q11~16 국경일** → 날짜가 여전히 들어가는가

## 여기서 배운 것 — 예시 쓰는 법

**작은 모델에게 예시는 본보기가 아니라 재료다.** 낱말까지 가져간다.

| 하지 말 것 | 대신 |
|---|---|
| 예시를 **하나만** 준다 | **둘** 을 준다 — 공통점만 남는다 |
| 예시에 **문제집의 답**을 쓴다 (안익태) | **안 나오는 것**으로 쓴다 (이순신) |
| 예시에 **베끼기 좋은 꼬리 문장**을 둔다 | 문장 모양을 예시마다 다르게 |
| **하지 말 것을 문장으로** 적는다 | 그 자리에 **할 일**을 적는다 (9/5) |

이 넷이 오늘까지 실제로 터진 것들이다. `RULES.md` 에 옮겨 둘 만하다.
