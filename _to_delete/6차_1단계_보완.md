# 6차 1단계 보완 — 기본 문제집을 읽지 못하는 이유

> 2026-09-09 · `assertionFailure("기본 문제집을 읽지 못했습니다: ...")` 대응

## 무엇이 났나

```
QuestionCatalog.loaded()
  → contentFile.loadBundled()
      → JSONDecoder().decode(QuestionPayload.self, ...)   ← 여기서 던진다
  → catch → assertionFailure
```

파일을 못 찾은 것이 아니다. **읽기는 읽었는데 해독에서 걸렸다.**

## 왜 걸리나

`Question` 에 이번에 두 칸을 더했다.

```swift
var tags: [String] = []
var facts: [QuestionFact] = []
```

`= []` 를 적어 두었으니 없어도 되겠거니 했는데, **Swift 가 자동으로 만들어 주는
`Codable` 은 기본값을 쓰지 않는다.** 자동 생성되는 해독 코드는 이렇게 생겼다.

```swift
self.tags = try container.decode([String].self, forKey: .tags)   // 없으면 throw
```

`decode` 이지 `decodeIfPresent` 가 아니다. 그래서 **키가 없으면 `keyNotFound` 를 던진다.**
기본값은 `Question(...)` 을 손으로 만들 때만 쓰인다.

`questions.json` 의 25문항에는 `tags` 도 `facts` 도 없다. 그래서 1번 문항에서 바로 멈춘다.

> **같은 함정이 두 군데 더 있다.**
> - `QuestionFact.weight` (`var weight: Int = 1`)
> - `GlossaryEntry.examples` (`var examples: [String] = []`)
>
> 사전 쪽은 `assertionFailure` 가 없어 **소리 없이 빈 사전이 된다.** 지금 `glossary.json` 의
> 「시조·도읍·건국이념·신화」 네 낱말에 `examples` 가 없으니 이미 그 상태다.

## 고르는 길

| | 방법 | 문제 |
|---|---|---|
| ⓐ | JSON 25문항에 `"tags": []`, `"facts": []` 를 다 적는다 | 칸을 더할 때마다 1,130문항을 손본다 |
| **ⓑ** | **해독기를 손으로 적어 `decodeIfPresent` 를 쓴다** | 파일에 없어도 된다 |

**ⓑ 로 간다.** 6차의 전제가 「서버가 문항을 늘린다」인데, 서버가 보낸 옛 파일에
새 칸이 없다고 앱이 안 켜지면 그 전제가 무너진다. **새 칸은 없어도 도는 것이 원칙이다.**

## 따라 칠 코드

### 1. `Data/Question.swift` — `Question` 안, `facts` 선언 바로 아래에 붙인다

```swift

    // MARK: - 해독

    /// 손으로 적은 해독기.
    ///
    /// 자동 생성되는 것은 **기본값을 쓰지 않아** 파일에 칸이 없으면 던집니다.
    /// 뒤에 더한 칸(``tags``·``facts``)은 옛 파일에 없는 것이 정상이므로
    /// 그 둘만 `decodeIfPresent` 로 받습니다.
    init(from decoder: Decoder) throws {
        let box = try decoder.container(keyedBy: CodingKeys.self)

        id              = try box.decode(Int.self,        forKey: .id)
        category        = try box.decode(String.self,     forKey: .category)
        unit            = try box.decode(String.self,     forKey: .unit)
        question        = try box.decode(String.self,     forKey: .question)
        answer          = try box.decode(String.self,     forKey: .answer)
        statementFormat = try box.decode(String.self,     forKey: .statementFormat)
        kind            = try box.decode(AnswerKind.self, forKey: .kind)
        difficulty      = try box.decode(Int.self,        forKey: .difficulty)

        tags  = try box.decodeIfPresent([String].self,      forKey: .tags)  ?? []
        facts = try box.decodeIfPresent([QuestionFact].self, forKey: .facts) ?? []
    }
```

> `init(from:)` 을 손으로 적으면 **다른 초기화 방법이 사라진다.** `Question(id:...)` 를
> 어딘가에서(미리보기·테스트) 쓰고 있으면 `extension Question { }` 안에 그 생성자를
> 따로 적어야 한다. 지금은 쓰는 곳이 없어 그냥 두면 된다.

### 2. `Data/Question.swift` — `QuestionFact` 를 통째로 바꾼다

```swift
struct QuestionFact: Codable, Hashable {
    /// 재료의 종류. date · year · event · wordplay · pairsWith · confusedWith · everyday
    let kind: String

    /// 먼저 쓸 순서. 높을수록 먼저.
    var weight: Int = 1

    let text: String

    init(kind: String, weight: Int = 1, text: String) {
        self.kind = kind
        self.weight = weight
        self.text = text
    }

    init(from decoder: Decoder) throws {
        let box = try decoder.container(keyedBy: CodingKeys.self)
        kind   = try box.decode(String.self, forKey: .kind)
        text   = try box.decode(String.self, forKey: .text)
        weight = try box.decodeIfPresent(Int.self, forKey: .weight) ?? 1
    }
}
```

### 3. `Data/Glossary.swift` — `GlossaryEntry` 를 통째로 바꾼다

```swift
/// 낱말 하나.
struct GlossaryEntry: Codable, Hashable {
    let word: String
    let gloss: String

    /// 이 낱말에 속하는 것들. 「국경일」의 삼일절·제헌절처럼.
    var examples: [String] = []

    init(word: String, gloss: String, examples: [String] = []) {
        self.word = word
        self.gloss = gloss
        self.examples = examples
    }

    init(from decoder: Decoder) throws {
        let box = try decoder.container(keyedBy: CodingKeys.self)
        word     = try box.decode(String.self, forKey: .word)
        gloss    = try box.decode(String.self, forKey: .gloss)
        examples = try box.decodeIfPresent([String].self, forKey: .examples) ?? []
    }
}
```

## 다음에 같은 함정을 피하는 법

**`Codable` 구조체에 칸을 더할 때는 `= 기본값` 만으로 끝내지 않는다.**
파일에 그 칸이 없을 수 있으면 `decodeIfPresent` 를 쓰는 해독기가 같이 있어야 한다.
